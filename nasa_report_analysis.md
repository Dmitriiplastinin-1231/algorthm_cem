### 3. Типичное содержание NASA отчётов по моделированию траекторий 1970-х годов

На основе анализа аналогичных документов NTRS этого периода
(например, NASA CR-2865, TN D-4816, CR-820 Greensite) отчёты по
траекторному моделированию 1970-х **стандартно содержат следующие разделы**:

#### 3.1 Уравнения движения ракеты ✅ (вероятно присутствует)

- 3DOF уравнения в проекциях на оси скоростной и связанной систем координат:
  ```
  m * dV/dt  = P*cos(α+δ) - D - m*g*sin(γ)
  m*V * dγ/dt = P*sin(α+δ) + N - m*g*cos(γ)
  ```
- 6DOF уравнения для анализа угловых движений
- Уравнения для угла атаки α и его связи с траекторными переменными

**Оценка:** В отчётах этой серии уравнения движения **практически всегда присутствуют**
(это основная база для всего моделирования). Степень детализации — от упрощённых 3DOF
до полных 6DOF с упругими колебаниями.

#### 3.2 Методы численного интегрирования ✅ (вероятно присутствует)

- В 1977 году стандартом для NASA была **схема Рунге-Кутты 4-го порядка (RK4)**,
  иногда с адаптивным шагом (методы Рунге-Кутты-Фельберга — RKF45).
- Типичный шаг интегрирования: Δt = 0.01–0.1 с.
- Ряд отчётов также описывал методы Адамса-Мултона (предиктор-корректор).

**Оценка:** Численные методы **вероятно описаны**, хотя могут занимать один раздел
без подробного вывода (предполагается знание читателем).

#### 3.3 Примеры расчёта траектории ✅ (вероятно присутствует)

- Типичная структура: задание начальных условий (широта старта, наклон старта,
  начальная масса, профиль тяги) → вывод таблиц h(t), V(t), γ(t), x_range(t)
- Визуализация: графики высоты, скорости, угла траектории
- Сравнение с лётными данными (если отчёт публикационный)

**Оценка:** Примеры расчётов **практически наверняка присутствуют** как демонстрация
работоспособности разработанного программного обеспечения.

### 5. Итоговый вердикт

> **Документ [NASA 19770012820] ЧАСТИЧНО применим для моделирования смещения траектории с морской платформы.**

**Что можно взять:**
- Уравнения движения ракеты в стандартной форме (3DOF / 6DOF)
- Схему численного интегрирования (RK4, шаг 0.01 с)
- Аэродинамические модели и атмосферные данные
- Структуру программы моделирования траектории

**Чего не хватает (нужны дополнительные источники):**
- Специфика старта с подвижного основания → **[2] Колесников 2003**
- Влияние задержки управления на точность → **[3] Blakelock 1991**
- Анализ устойчивости с задержкой τ = 0.3 с → **[8] Smith 1959**, **[11] Niculescu 2001**

### 6. Рекомендация по использованию документа

Документ **[7] Frosch & Vallely 1967** («Saturn AS-501/S-IC Flight Control System Design»)
из вашего списка литературы **БОЛЕЕ конкретен** для вашей задачи, чем NASA 19770012820:

- Frosch описывает **реальную систему управления** с задержкой ~0.2 с
- Содержит конкретные числа TVC: отклонение ±6°, скорость 5°/с
- Методология численного моделирования аналогична (RK4, шаг 0.01 с)

**Итог:** Если доступ к документу 19770012820 ограничен — его функцию для вашей задачи
полностью покрывает связка **[7] Frosch + [1] Лебедев-Чернобровкин + [2] Колесников**.
